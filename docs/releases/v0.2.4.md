# Conversation Manager v0.2.4

本版本新增暗色模式与更直观的连接状态展示，修复列表操作时整页滚动的布局问题，并让浏览器扩展配对全程零点击。

## 更新内容

- 新增暗色模式：跟随系统深色模式自动切换，列表、对话框、设置页与滚动条均已适配。
- 侧边栏新增连接状态块：ChatGPT 桥接与 Codex 服务的连接状态以文字加状态点常驻显示，状态点带同色光环。
- 空列表区分“从未同步过”与“筛选无结果”：前者按连接状态给出同步或重连指引，后者提供一键清除筛选。
- 修复点击或用方向键移动会话时整个页面被滚动的布局问题。
- 浏览器扩展在未配对状态下自动向桌面端发起配对，加载扩展后无需任何点击即可完成连接；连接引导卡片不再显示“打开扩展目录”按钮。
- Codex 任务列表中“非项目任务”分组固定显示在所有项目文件夹之前。
- 侧边栏宽度微调收窄。

## 接口边界

统一 ChatGPT/Codex 桌面客户端公开的 `codex app-server` 目前只提供 Codex 任务接口，不提供 ChatGPT 云端聊天管理接口。ChatGPT 会话继续通过配套 Chrome/Edge 扩展复用浏览器登录状态；应用不读取桌面客户端私有 Cookie、数据库或凭据文件。

## 文件

- `Conversation-Manager-0.2.4-setup-x64.exe`：Windows x64 安装版，包含卸载程序。
- `Conversation-Manager-0.2.4-portable-x64.exe`：Windows x64 便携版。
- `Conversation-Manager-Bridge-0.2.4.zip`：Chrome/Edge 浏览器桥接扩展。
