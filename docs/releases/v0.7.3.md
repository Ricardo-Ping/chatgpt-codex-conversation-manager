# Conversation Manager v0.7.3

本版本根治 ChatGPT 会话读取挂起问题（标签页无响应检测 + 快速明确报错），修复扩展自动更新机制，并对统计洞察面板做了完整的视觉与可用性抛光。

## ChatGPT 会话读取挂起（根治）

- 根因：扩展把读取命令转发到 chatgpt.com 标签页执行，但页面消息没有超时——当该标签页被 Chrome 冻结/内存节省休眠（后台标签页的常见状态）或进入假死时，消息永远没有应答，桌面端要等满整个超时预算才报"同步或操作超时"，且每次重试都重复发生。
- 现在页面消息限时 60 秒：无响应立即中止并返回明确错误「ChatGPT 页面 60 秒无响应（可能已被 Chrome 冻结），请刷新该标签页后重试」。
- 多标签容错：优先使用最近使用的 ChatGPT 标签页，最多尝试两个；全部无响应时返回 `CHATGPT_TAB_UNRESPONSIVE` 并附刷新指引。
- 配合 v0.7.2 已引入的 ChatGPT 后端请求 45 秒限时，读取链路的每一环都有明确预算：正常时秒级加载，异常时约 1 分钟内给出可操作的原因。

## 扩展自动更新机制修复

- 原机制的缺陷：`chrome.runtime.reload()` 只会重读 Chrome 当初加载的那个文件夹；若 Chrome 加载的是旧目录（手动解压的 zip 等），应用更新后重载读到的仍是旧文件，版本永远落后。
- 现在桌面端每次启动都会把最新扩展文件同步到固定稳定目录 `~/.conversation-manager/extension`（仅在文件变化时写入）。
- **Chrome 只需加载该目录一次，之后扩展随桌面端更新自动升级，永不需要人工重载**。设置页「浏览器桥接」的「打开扩展目录」即指向该目录；若此前加载过旧目录，按设置页新增的引导切换一次即可。

## 统计洞察面板（修复与抛光）

- 修复项目 Top 8 显示内部 ID（g-p-xxxx）的问题：自动补全 ChatGPT/Codex 项目名称，缺失时回退为「未命名项目」+ 短 ID。
- 平台占比环形图重做：环心显示总会话总数，移除外挂悬空标签，扇区描边分隔，图例移至底部。
- 修复页面边界与滚动：统计页现在与工作区/设置页使用相同的容器约束——有正常边界留白、可以顺畅下滑到页面底部。
- 近 30 天趋势图图例移至右上角，tooltip 统一为主题化样式（跟随浅色/深色）。
- KPI 卡片增加彩色标识条与首卡高亮；卡片标题增加品牌色标记。

## 会话列表

- 修复分组头长文件夹名换行挤压的问题：分组头保持单行，超长名称省略号截断，右侧计数/路径不再与之挤压。

## 工程化

- 扩展标签页消息超时、多标签容错纳入扩展测试；共享纯函数（dedupeById、isValidVersionFormat、threadFingerprint）补齐单元测试；whenReady 启动流程格式化为可读多行结构。

## 升级说明

- **重要**：升级后请在 `chrome://extensions` 中将扩展目录切换一次（设置 → 浏览器桥接 → 打开扩展目录，按页内指引加载），此后扩展永久自动更新。
- 若 ChatGPT 读取仍超时，请刷新浏览器中的 ChatGPT 标签页后重试——新版会在约 1 分钟内给出明确的错误原因，不再无限挂起。

## 接口边界

ChatGPT 读取、同步、导出依赖浏览器扩展与 chatgpt.com 后端的可用性；统计面板基于本地缓存索引，检索范围为已同步内容。其余功能不受影响。
