# Conversation Manager v0.3.2

本版本新增会话保存能力、设置页运行日志窗口，并统一 Codex 状态计数显示。

## 更新内容

- 新增“保存会话”功能：ChatGPT 与 Codex 操作栏在归档旁新增保存按钮，选中会话后选择本地文件夹，即可把每条会话导出为独立的 Markdown 文件（含标题、来源、时间与按角色分节的消息正文）。
- ChatGPT 会话正文通过扩展调用官方会话接口读取，扩展内预先提取角色与文本以减小传输体积；结果体上限从 1MB 提升到 8MB 以兼容长会话。
- Codex 任务正文通过 App Server 的 `thread/read` 接口读取；若接口未返回正文，自动降级为任务元数据摘要并在文件内注明原因。
- 设置页新增“运行日志”窗口：实时流式显示应用日志，支持刷新、清空与保存到本地文件；日志仅保存在本机并自动轮转。
- Codex 的未归档/已归档状态显示数量徽标，与 ChatGPT 一致；归档与恢复会在两个状态的计数间正确转移。
- 扩展在转发桌面命令期间主动保持 Service Worker 活跃，长事务不再因后台休眠超时；向标签页注入桥接脚本后增加带退避的多次重试。

## 升级说明

更新后请在 `chrome://extensions` 中重新加载 Conversation Manager Bridge，使浏览器内扩展同步到新版本（保存会话的 ChatGPT 端依赖新命令）；版本不一致时侧边栏会出现黄色“需重载”提示。

## 接口边界

统一 ChatGPT/Codex 桌面客户端公开的 `codex app-server` 目前只提供 Codex 任务接口，不提供 ChatGPT 云端聊天管理接口。ChatGPT 会话继续通过配套 Chrome/Edge 扩展复用浏览器登录状态；应用不读取桌面客户端私有 Cookie、数据库或凭据文件。

## 文件

- `Conversation-Manager-0.3.2-setup-x64.exe`：Windows x64 安装版，包含卸载程序。
- `Conversation-Manager-0.3.2-portable-x64.exe`：Windows x64 便携版。
- `Conversation-Manager-Bridge-0.3.2.zip`：Chrome/Edge 浏览器桥接扩展。
