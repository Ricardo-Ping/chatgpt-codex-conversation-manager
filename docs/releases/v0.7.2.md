# Conversation Manager v0.7.2

本版本带来统计洞察面板、系统托盘与全局快捷搜索、MCP 扩展到 ChatGPT 侧三大新能力；同时修复 ChatGPT 会话读取挂起、导出图片离线可见等一系列问题。

## 统计洞察面板（新）

- 侧边栏新增「统计」独立页面：总会话 / 未归档 / 已归档 / 未命名占比四张 KPI 数字卡。
- 近 30 天每日新增趋势（ChatGPT / Codex 分色堆叠柱状）、平台占比环形图、项目 Top 8 条形图，基于 ECharts 按需引入。
- 图表配色直接读取应用主题变量，浅色 / 深色 / 跟随系统三态即时联动。
- 底部洞察列表可点击跳转对应工作区：未命名会话建议重命名、超过 90 天未动建议归档。
- 数据全部来自本地索引，零外部请求；页头常驻「基于本地索引 · 最近同步」口径提示，支持手动刷新，快照跨页面缓存。

## 系统托盘 + 全局快捷键（新）

- 应用驻留系统托盘：关闭主窗口即最小化到托盘，托盘菜单可打开主窗口、呼出快速搜索或退出。
- 全局快捷键 `Alt+Shift+Space` 随时呼出快速搜索窗：无边框置顶小窗，跨平台联合检索 ChatGPT 缓存会话与 Codex 任务，Enter 直接打开对应会话，失焦自动隐藏。
- 设置页新增「托盘与快捷键」说明。

## ChatGPT 读取稳定性修复

- 修复双击打开会话长时间停留在「正在加载会话内容…」的问题：扩展端对 ChatGPT 后端的请求此前没有超时，偶发的连接挂起会堵死串行转发队列，导致后续所有读取都在 5 分钟后才统一超时。
- 现在单次请求限时 45 秒，超时自动中止并给出明确原因（检查网络或代理后重试），不再阻塞后续操作。

## 「在应用中打开」（改进）

- 阅读面板的「在终端打开」升级为「在应用中打开」：通过 ChatGPT 桌面客户端注册的 `codex://` 深链，直接在其原生界面打开对应 Codex 会话，无需终端。
- 深链调用前先检测系统协议处理程序确实存在，避免未安装客户端时弹出系统选择框或静默失败；此时自动回退终端方案，仍失败则复制恢复命令并提示。

## 导出修复

- ChatGPT 导出 Markdown 现在会把成功下载的图片改写为本地相对路径，真正实现离线可查看；下载失败的保留原始链接。
- 图片按会话独立子目录存放，批量导出不再互相覆盖；移除单会话 30 张图片的静默截断。

## MCP 扩展到 ChatGPT 侧（新）

- 配套 MCP server 新增 6 个 ChatGPT 工具：`chatgpt_status`、`search_chatgpt_conversations`、`read_chatgpt_conversation`、`archive_chatgpt_conversations`、`restore_chatgpt_conversations`、`export_chatgpt_conversations`。
- Claude Code / Cline / Cursor 等任意 MCP 客户端现在可以搜索、读取、归档和导出你的 ChatGPT 会话（删除操作刻意未暴露）。
- 发现机制：桌面端启动时写入 `~/.conversation-manager/mcp-endpoint.json`（密钥 0600，仅本机回环），MCP 侧自动读取认证。

## 列表虚拟滚动

- 会话列表改用 @tanstack/react-virtual 虚拟化：只渲染视口内条目，上万条会话滚动依旧流畅；移除原先「先加载 100 条、滚动追加」的分批逻辑。
- 阅读面板「上一个 / 下一个」与键盘 ↑/↓ 导航覆盖全部过滤结果，不再受分批加载限制。

## 其他修复

- 阅读面板：Codex 文件引用标记转为可读引用；本地路径图片按 `~/.codex` 白名单转换为 `file:///` 显示；⤒ 跳转顶部按钮不再遮挡关闭按钮。
- Codex 连接扫描失败后进入 60 秒冷却，不再被状态轮询反复触发全量进程探测；手动选择命令立即重置。
- 结构化重构：主进程拆分 updater / preferences / ipc-sanitize 模块，渲染端拆分设置页 / 快速搜索 / 分段控件；共享纯函数（dedupeById、isValidVersionFormat、threadFingerprint）收拢到共享包并补齐测试。

## 工程化

- 新增 push/PR 触发的 CI 门禁：i18n 翻译键审计 + typecheck + test + lint，翻译缺失与 Linux 专属失败在合并前拦截。
- 新增 `pnpm bump <version>` 一键同步全部版本号（各包、扩展 manifest、MCP 常量、README 链接）；发布时校验根/桌面/扩展三处版本一致。
- lint 改为全仓库扫描；主进程中英词典键一致性纳入审计。

## 升级说明

- 扩展随桌面端自动升级；若升级后读取异常，请在 `chrome://extensions` 中手动刷新一次 Conversation Manager Bridge。
- 从旧版本升级后，关闭主窗口不会退出应用，应用将驻留系统托盘；完全退出请使用托盘菜单的「退出」。

## 接口边界

`codex://` 深链依赖 ChatGPT 桌面客户端的协议注册，未安装客户端时自动回退到终端 CLI 方案；ChatGPT 会话检索基于本地缓存索引，检索范围为已同步内容。统计面板数据口径同理。
