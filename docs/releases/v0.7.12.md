# Conversation Manager v0.7.12

维护版本：两件事——**ChatGPT 多账号切换真正"无感"**（网页里切换登录后，管理器自动跟随并同步对应账号，各账号数据独立保存）与**修复 v0.7.11 的三处界面问题**（任务行挤压、会话 ID 前缀与字体、统计表格溢出）。

## ChatGPT 多账号：切换登录自动跟随

- **问题根源**：账号按浏览器登录的账号结构哈希分桶保存。在网页里切换登录后，桌面端仍用旧账号的 key 请求，扩展在新登录的账号列表里找不到匹配项，于是报「找不到匹配的 ChatGPT 账号」且列表停留在旧缓存。
- **现在自动跟随**：同步时检测到账号失配，自动切换到新登录的默认账号并完整同步，提示「已检测到浏览器登录的 ChatGPT 账号变化，已切换到 {label}…」；不同账号的数据始终**独立分桶保存**，切回旧登录会自动切回对应桶并增量续传，互不污染。
- **扩展端自愈**：账号不匹配时先强制重新认证（刷新缓存的登录结构与令牌）再匹配一次，避免后台服务缓存旧登录导致误报；错误码细化为 `ACCOUNT_NOT_FOUND`，桌面端据此精确触发恢复。
- 连接恢复与同步失败两条路径都会触发自动恢复；旧版扩展场景优雅降级为原有提示，不会出现未处理异常。

## 界面修复（v0.7.11 回归）

- **Codex 任务行不再挤压**：打开阅读面板后列表变窄时，复制会话 ID / 打开文件夹 / 打开文件按钮与用量徽标改为按列表实际宽度自适应隐藏（先隐藏徽标，极窄时仅保留时间），不再叠在会话标题上。
- **会话 ID 展示净化**：去掉实例名前缀（kan / shi / skill-x20 等），只显示中段省略的会话 ID；字体从等宽改为与应用一致的默认字体。
- **统计表格溢出**：窄窗口下「按模型 / 按实例」表格不再溢出卡片边框——根因是统计页隐式网格轨道被子卡片内容撑宽，现已固定轨道宽度，放不下的表格在卡片内横向滚动；页面不再出现横向滚动条。

## 稳健性

- 新增「登录切换后自动重认证并匹配新账号」与「未知账号仍拒绝」等扩展测试，扩展 24 项、桌面 96 项等全部单元测试通过；typecheck、ESLint、中英文案审计通过；全部改动经 `verify-all` 全量门禁与 pre-push 钩子验证，多账号切换流程经浏览器端到端模拟验证（切换 → 自动恢复 → 独立桶同步 → 可写状态恢复）。

## 升级说明

- 从 v0.7.x 正常升级即可，无需任何人工操作。扩展随桌面端自动更新；已有的各账号缓存不受影响，切换账号不会重复占用空间。
