# Conversation Manager v0.7.15

功能版本：统计页分析能力全面升级——**按模型堆叠趋势、统计联动跳转、用量报表导出**；ChatGPT 新增**本地标签与收藏**；Codex 用量新增**每日预算提醒**，费用估算校准为 OpenAI 公开定价。

## 统计页：按模型堆叠趋势

- 趋势图新增「总量 / 按模型」维度切换：按模型模式下以堆叠柱状图展示各模型消耗占比随时间的变化，图例自动去重排序、可滚动。
- Tokens 与请求数两种指标均支持堆叠视图；悬浮提示按当前维度展示各模型明细与合计。

## 统计联动跳转：从「看」到「入口」

- **按实例**表行点击 → 跳转到 Codex 任务列表并按该实例（工作目录）过滤；Codex 列表工具栏新增实例筛选下拉，可随时切回全部。
- **按日期**表行点击 → 热力图卡片自动滚动聚焦并高亮该日期（单元格描边标记，可关闭）；若日期超出当前热力图窗口会自动切换。
- **最耗会话**表行点击 → 按 ID 定位会话；会话搜索现在支持完整会话 ID 匹配（≥8 字符生效，避免短关键词误匹配）。

## 用量报表导出

- 用量卡新增「导出报表」：一键生成 CSV 或 Markdown 报表，含总计与按模型 / 按实例 / 按日期分节；CSV 带 BOM，Excel 直接打开不乱码。

## ChatGPT：本地标签与收藏

- 会话行新增**收藏星标**（点击切换）与**标签体系**：右键菜单「标签」子菜单可勾选归属，或「新建标签…」即时命名。
- 工具栏新增「按标签筛选」下拉（全部会话 / ★ 收藏 / 各标签），会话行显示 #标签。
- 标签与收藏完全保存在本机（`conversation-metadata.json`），不影响云端任何数据。

## Codex 用量：预算提醒与官方价目

- **每日用量预算提醒**：设置阈值（万 tokens/天）后，当日用量超过预算当天系统通知一次，点击通知打开主窗口。
- **内置价目表校准**为 OpenAI 公开定价页的实际价格（gpt-6 全系 / gpt-5.6 全系 / gpt-5.5 / gpt-5.3-codex / gpt-5.4 等，2026-09 校对），估算费用更接近真实。
- 设置页新增「Codex 用量与预算」：价目规则按模型前缀编辑（$/百万 Tokens，优先于内置价格），支持增删与校验。

## 其他

- 侧边栏版本号与作者名可点击：版本 → GitHub Releases 页，作者 → GitHub 主页。
- MCP 新增 `codex_token_usage` 工具：外部 AI 客户端可查询用量摘要与最耗会话排行（支持 since / 实例 / 数量参数）。

## 稳健性

- 桌面 102 项、扩展 24 项、域层 8 项等全部单元测试通过；typecheck、ESLint、中英文案审计通过；全部改动经 `verify-all` 全量门禁与 pre-push 钩子验证，界面经浏览器多场景实测。

## 升级说明

- 从 v0.7.x 正常升级即可，无需任何人工操作。扩展随桌面端自动更新；已有缓存、标签、收藏与账号数据不受影响。首次使用 Codex 用量统计时会自动构建本地索引。
