# Conversation Manager v0.6.4

本版本修复 Codex 阅读面板不显示内容的问题，并按wolai风格重做了代码块观感；ChatGPT 会话的打开速度也显著提升。

## 更新内容

### 修复

- **Codex 阅读面板空白**：`thread/read` 需要显式携带 `includeTurns` 才返回会话内容，新版 App Server 默认只回元数据，导致面板显示"没有可显示的会话内容"。已修复，并兼容多种协议版本的内容形态（含数组型文本片段）。

### 体验

- **代码块视觉重做（wolai 风格）**：由纯黑背景改为随主题自适应的浅色表面（深色主题为协调的深青配色）；每个代码块顶部带语言标签栏与一键复制按钮；语言标注缺失时自动检测语言再高亮；语法配色采用 GitHub 风格方案，关键字、字符串、注释、函数、数字各有区分。
- **ChatGPT 会话打开提速**：读取命令改走快速通道，不再排在长同步后面排队；已读会话在主进程缓存 10 分钟，重复双击直接秒开。

### 其他

- README 功能亮点与架构文档同步当前实现；性能上对列表分组与切片做了 memo 化。

## 升级说明

- 请在 `chrome://extensions` 中重新加载 Conversation Manager Bridge。
- macOS / Windows 均可通过应用内自动更新升级到本版本。

## 接口边界

`thread/read` 的 `includeTurns` 属于 App Server 的协议参数，需要较新版本的 ChatGPT/Codex 桌面客户端；旧版本客户端上 Codex 阅读面板可能仍显示为空。ChatGPT 侧功能不受影响。

## 文件

- `Conversation-Manager-0.6.4-setup-x64.exe`：Windows x64 安装版，包含卸载程序。
- `Conversation-Manager-0.6.4-portable-x64.exe`：Windows x64 便携版。
- `Conversation-Manager-0.6.4-mac-arm64.zip`：macOS（Apple Silicon）应用包，解压即用，支持应用内自动更新。
- `Conversation-Manager-0.6.4-dmg-arm64.dmg`：macOS（Apple Silicon）DMG 镜像。
- `Conversation-Manager-Bridge-0.6.4.zip`：Chrome/Edge 浏览器桥接扩展。
