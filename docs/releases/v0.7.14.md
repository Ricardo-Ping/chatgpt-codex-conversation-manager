# Conversation Manager v0.7.14

小版本：**重构统计页「Codex 会话用量」的三张明细表（按模型 / 按实例 / 按日期）**，解决选择「全部」时间范围时按实例列表把整页拉得极长、按模型卡片大片留白的不平衡布局。纯界面改进，数据与统计口径无任何变化。

## 用量明细表：高度封顶 + 卡片内滚动

- **页长稳定**：三张表的卡片高度统一封顶（320px），行数再多也在卡片内部滚动——选择「全部」时几十个实例不再把「按日期」和热力图推到一屏之外。
- **卡片等高对齐**：按模型与按实例并排时高度强制一致，行数少的一侧不再出现大片空白。
- **标题栏与表头常驻**：滚动时卡片标题（按实例 / 按日期）和列头（输入 / 缓存 / 输出…）始终可见，滚到任何位置都能对上列含义。
- **条目数徽标**：每张表标题旁显示条目总数（如 `按实例 · 36`、`按日期 · 120`），滚动浏览时对数据量心中有数。
- **细滚动条**：替换 Windows 默认的粗滚动条，更贴合整体界面风格。
- 自适应行为保留：行数少的场景（如近 7 天只有几个模型）卡片按内容收缩，不强制撑高。

## 稳健性

- 桌面 96 项单元测试、typecheck、ESLint、中英文案审计全部通过；`verify-all` 全量门禁与 pre-push 钩子验证；布局经浏览器实测「全部」（180 天 / 36 实例 / 120 日期行）与「近 7 天」（少行数）两种极端场景。

## 升级说明

- 从 v0.7.x 正常升级即可，无需任何人工操作。扩展随桌面端自动更新；已有缓存与账号数据不受影响。
