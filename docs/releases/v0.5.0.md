# Conversation Manager v0.5.0

本版本完成 macOS（Apple Silicon）适配，导出的 Markdown 文件跟随界面语言，并修复导出与界面上的若干问题。

## 更新内容

- macOS（Apple Silicon）适配完成：Codex 探测路径（ChatGPT.app 内置二进制、Homebrew、npm 全局）、mac 应用菜单（Cmd+C/V/Q）、arm64 打包配置（zip + dmg）、深色模式支持与专属应用图标。mac 安装包将在 macOS 环境构建后随 Release 提供。
- 导出的 Markdown 文件跟随界面语言：英文界面导出英文结构的文档，中文界面保持中文结构。
- 修复导出会话时的账号解析错误：此前读取会话正文使用了错误的账号标识，导致 ChatGPT 端导出必然鉴权失败。
- 扩展弹窗与配对错误提示跟随浏览器语言双语显示。
- 记住上次“保存会话”的导出目录，下次保存自动定位。
- 分段切换控件的滑动指示器在语言切换与窗口缩放后正确重算位置与尺寸。

## macOS 使用说明

- 首次打开需手动放行：右键点击应用选择“打开”，或在系统设置中允许。
- 首次运行桥接时会弹出防火墙询问，允许即可。
- 当前 macOS 版暂不支持自动更新，新版本请从 Releases 页面手动下载。

## 接口边界

统一 ChatGPT/Codex 桌面客户端公开的 `codex app-server` 目前只提供 Codex 任务接口，不提供 ChatGPT 云端聊天管理接口。ChatGPT 会话继续通过配套 Chrome/Edge 扩展复用浏览器登录状态；应用不读取桌面客户端私有 Cookie、数据库或凭据文件。

## 文件

- `Conversation-Manager-0.5.0-setup-x64.exe`：Windows x64 安装版，包含卸载程序。
- `Conversation-Manager-0.5.0-portable-x64.exe`：Windows x64 便携版。
- `Conversation-Manager-Bridge-0.5.0.zip`：Chrome/Edge 浏览器桥接扩展。
