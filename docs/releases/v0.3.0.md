# Conversation Manager v0.3.0

本版本引入统一的应用图标。

## 更新内容

- 全新统一应用图标：窗口标题栏、任务栏、安装程序与侧边栏品牌区使用同一图标，替换原先的“CM”字样标识和 Electron 默认图标。

本版本同时包含 v0.2.9 的全部改进（列表滚动修复、后台增量同步、周期性完整校准、缓存一致性保护等），未升级的用户会一并获得。

## 接口边界

统一 ChatGPT/Codex 桌面客户端公开的 `codex app-server` 目前只提供 Codex 任务接口，不提供 ChatGPT 云端聊天管理接口。ChatGPT 会话继续通过配套 Chrome/Edge 扩展复用浏览器登录状态；应用不读取桌面客户端私有 Cookie、数据库或凭据文件。

## 文件

- `Conversation-Manager-0.3.0-setup-x64.exe`：Windows x64 安装版，包含卸载程序。
- `Conversation-Manager-0.3.0-portable-x64.exe`：Windows x64 便携版。
- `Conversation-Manager-Bridge-0.3.0.zip`：Chrome/Edge 浏览器桥接扩展。
