# Conversation Manager v0.6.0

本版本新增 CI 双平台自动构建，补全 mac dmg 安装镜像，并完成界面语言切换与同步稳定性优化。

## 更新内容

- 新增 GitHub Actions 双平台构建流水线：推送 `v*` 标签时自动在 Windows 与 macOS 环境构建安装包并发布 Release，同时校验标签与包版本一致。
- mac 安装包同时提供 dmg（图形安装）与 zip（解压即用）两种格式。
- 新增界面语言切换：设置 → 外观中可在中文与 English 之间切换，选择持久化保存，即时生效；默认简体中文，macOS 首次运行跟随系统语言。
- 主进程消息（更新提示、对话框标题等）与全部界面文案已接入双语词典。
- 桥接状态轮询优化：长轮询挂起时间调整为 10 秒，连接状态显示更稳定；同步活动写入运行日志。
- 扩展弹窗与配对提示双语显示，跟随浏览器语言。
- 分段切换控件的滑动指示器在语言切换与窗口缩放后正确重算位置与尺寸。

## macOS 安装说明（Apple Silicon）

> 当前 macOS 包未做 Apple Developer 签名与公证，首次打开可能被 Gatekeeper 拦截，属正常现象。

- **方式一（图形界面）**：下载 `Conversation-Manager-0.6.0-mac-arm64.zip` 解压，右键点击应用选择「打开」确认；或在「系统设置 → 隐私与安全性」中点击「仍要打开」。
- **方式二（命令行，推荐）**：`curl` 下载的文件不携带隔离标记：

```bash
curl -LO "https://github.com/Ricardo-Ping/chatgpt-codex-conversation-manager/releases/download/v0.6.0/Conversation-Manager-0.6.0-mac-arm64.zip"
```

- 加载浏览器扩展后 30 秒内自动配对；`thread/read` 内容读取需要在 chatgpt.com 页面打开的状态下使用。

## 升级说明

更新后请在 `chrome://extensions` 中重新加载 Conversation Manager Bridge，使浏览器内扩展同步到新版本；版本不一致时侧边栏会出现黄色“需重载”提示。

## 接口边界

统一 ChatGPT/Codex 桌面客户端公开的 `codex app-server` 目前只提供 Codex 任务接口，不提供 ChatGPT 云端聊天管理接口。ChatGPT 会话继续通过配套 Chrome/Edge 扩展复用浏览器登录状态；应用不读取桌面客户端私有 Cookie、数据库或凭据文件。

## 文件

- `Conversation-Manager-0.6.0-setup-x64.exe`：Windows x64 安装版，包含卸载程序。
- `Conversation-Manager-0.6.0-portable-x64.exe`：Windows x64 便携版。
- `Conversation-Manager-0.6.0-mac-arm64.zip`：macOS（Apple Silicon）应用包，解压即用。
- `Conversation-Manager-0.6.0-dmg-arm64.dmg`：mac 图形化安装镜像。
- `Conversation-Manager-Bridge-0.6.0.zip`：Chrome/Edge 浏览器桥接扩展。
