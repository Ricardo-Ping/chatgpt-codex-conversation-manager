# Conversation Manager v0.7.11

本版本带来两组重头功能：**统计页的 Codex 真实 Token 用量统计**（从本机会话日志还原每次请求的真实消耗）与 **Codex 任务行的会话文件直达操作**（会话 ID / 打开日志文件 / 行内用量徽标）。全部数据只来自本机，只读计数、不读会话正文。

## 统计页新增「Codex 会话用量」

- **真实用量，而非配额推测**：增量扫描本机 `~/.codex` 会话日志（rollout JSONL）中的 `token_count` 事件，按每次请求的增量（`last_token_usage`）汇总输入 / 缓存输入 / 输出 Tokens、请求数与估算费用；同一请求的重复上报（total 未增长）自动去重。
- **六格指标瓦片**：输入、缓存输入、输出、合计 Tokens（中文按亿/万、英文按 K/M/B 记法），请求数与估算费用；悬停可看精确数值。
- **每日趋势折线图**：合计 Tokens 与请求数一键切换，渐变面积 + 日均参考线，支持近 7 / 30 / 90 天 / 全部时间范围。
- **三张明细表**：按模型、按实例（工作目录）、按日期，合计列内嵌占比条；日期表 newest-first、表头吸顶滚动。
- **实例筛选**：右上角下拉按工作目录实例筛选，瓦片、图表与三张表全部联动。
- **只读且克制**：只解析 token 计数事件，不读会话正文；mtime/size 未变的文件直接走本地缓存（`codex-usage-cache.json`），重复扫描近乎零开销；「重新扫描」按钮可强制全量重解析。费用按公开 API 价格估算，仅作参考。

## Codex 任务行：会话文件直达

- **行内会话元信息**：标题下方显示实例（工作目录，无目录显示「默认实例」）与中段省略的会话 ID（等宽字体，悬停显示完整 ID）。
- **三个直达操作**：一键复制完整会话 ID（反馈 ✓）、打开会话日志文件所在文件夹、直接打开会话 JSONL 文件。路径只在主进程内从扫描索引解析，渲染端不传路径。
- **行内用量徽标**：蓝色胶囊实时展示该会话文件的输入 / 输出 Tokens（如 `22.0M / 81.7K tokens`），悬停显示缓存、请求数与估算费用明细；没有对应日志文件的任务不显示。
- 以上能力与统计页共用同一套增量扫描缓存：列表刷新时只对变更文件重新解析，通常几百毫秒内完成。

## 修复

- **平台占比图中心的总会话数字此前从未显示**：ECharts 按需注册遗漏 `TitleComponent`，中心的"总会话"标题一直被静默忽略；补注册后正常显示。
- 统计页「重新扫描」后，Codex 任务行的用量索引现在会同步失效重建，两处数据不再出现短暂不一致。
- 会话日志文件被外部移动/删除后，「打开会话文件」现在如实返回未打开，而不是假成功。

## 稳健性

- 解析器对旧版日志（缺失 `last_token_usage`）按累计差值推导增量，不再把此前的量重复计入；负差值钳到 0。
- 渲染端对桥接方法缺失（旧 preload 热更新场景）做了防御：用量拉取静默跳过、行内按钮自动隐藏，不再可能出现未处理异常。
- 新增 21 项单元测试（JSONL 解析与去重、增量缓存、线程索引、范围/实例聚合、数字格式化），桌面端合计 96 项测试通过；typecheck、ESLint、中英文案审计通过；全部改动经 `verify-all` 全量门禁与 pre-push 钩子验证，并用本机真实会话日志做过端到端数值比对。

## 升级说明

- 从 v0.7.x 正常升级即可，无需任何人工操作。首次打开统计页或 Codex 任务列表时会做一次全量日志扫描（数百个文件约几秒），之后增量扫描近乎瞬时。
