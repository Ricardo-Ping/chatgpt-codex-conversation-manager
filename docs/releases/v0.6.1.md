# Conversation Manager v0.6.1

本版本补全开源许可文件，并精简发布产物。

## 更新内容

- 新增 LICENSE 文件（MIT）：包含版权声明、作者（Ricardo-Ping）与项目地址。
- 移除独立的扩展 `zip.sha256` 校验文件：其校验和已由 `SHA256SUMS.txt` 统一覆盖，减少重复产物。
- package 元数据补全 author / license / homepage / repository 字段。

## 升级说明

更新后请在 `chrome://extensions` 中重新加载 Conversation Manager Bridge，使浏览器内扩展同步到新版本；版本不一致时侧边栏会出现黄色“需重载”提示。

## 接口边界

统一 ChatGPT/Codex 桌面客户端公开的 `codex app-server` 目前只提供 Codex 任务接口，不提供 ChatGPT 云端聊天管理接口。ChatGPT 会话继续通过配套 Chrome/Edge 扩展复用浏览器登录状态；应用不读取桌面客户端私有 Cookie、数据库或凭据文件。

## 文件

- `Conversation-Manager-0.6.1-setup-x64.exe`：Windows x64 安装版，包含卸载程序。
- `Conversation-Manager-0.6.1-portable-x64.exe`：Windows x64 便携版。
- `Conversation-Manager-0.6.1-mac-arm64.zip`：macOS（Apple Silicon）应用包，解压即用。
- `Conversation-Manager-Bridge-0.6.1.zip`：Chrome/Edge 浏览器桥接扩展。
