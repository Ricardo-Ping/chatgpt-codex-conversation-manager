# Conversation Manager v0.7.0

本版本引入全新的应用内会话阅读面板、ChatGPT 与 Codex 项目管理、扩展自重载和 macOS 自研自动更新器；同时修复同步超时、双语翻译缺失等十余项问题。

## 会话阅读面板（新）

- 在 ChatGPT 与 Codex 列表中双击任意会话，应用内右侧滑入阅读面板，完整展示会话内容，不再需要跳转浏览器或终端。
- 支持 Markdown 富文本（GFM 表格、引用、链接）、18 种语言的代码块语法高亮与一键复制、图片内联显示与懒加载。
- 面板头部提供「上一个」「下一个」「复制全文」「在浏览器/终端打开」与关闭按钮；列表始终保持可交互，双击其他会话即可切换内容；Esc 或点击空白处关闭。
- ChatGPT 生成图片通过文件下载接口解析为可用地址后直接显示。
- 用户消息靠右对齐、助手消息靠左对齐，角色标签自动标注来源平台（ChatGPT / Codex）。
- 工具调用与系统消息自动隐藏，不干扰正常阅读。

## 项目管理

- ChatGPT「工作」视图按项目文件夹分组展示，分组标题即时反映项目名称。
- 右键菜单支持「添加到项目」（子菜单列出全部项目）与「移出项目」，操作实时同步回 ChatGPT / Codex。
- 批量移动：勾选多条会话后一键移入/移出项目。
- Codex 项目列表具备自愈能力：枚举结果与会话缓存自动取并集，加载失败自动重试并支持点击重试。
- Codex 按工作目录分组的会话支持「移出文件夹」，归入「非项目任务」分组并可随时恢复。

## 同步稳定性

- 根治同步超时：批量变更等短命令改走快速通道，不再被长同步阻塞；后台轮换同步在繁忙时自动让路。
- 项目会话抓取并发翻倍，同步耗时约减半；超时预算统一为 5 分钟。
- 超时提示本地化并给出自助解决指引。

## 浏览器扩展

- 桌面端更新后，扩展通过版本协商自动完成自我重载，无需手动操作。
- 项目收集结果写入运行日志，便于核对。

## macOS 自动更新（正式版）

- macOS 转正：内置自研替换式更新器，未签名应用也可自动完成升级。
- 自动更新开启时全程无感；应用目录不可写时明确提示，并保留「打开下载页」手动兜底。

## 设置页

- 新增「开机启动」开关（默认关闭），Windows 写注册表、macOS 走系统登录项。
- 新增「数据备份/恢复」：导出/导入索引缓存与偏好设置文件，支持跨设备迁移。
- Codex 后端路径展示风格与扩展目录统一。
- 阅读面板消息时间戳、思考内容视觉弱化、代码块大小约束等打磨。

## 代码质量

- 清理 16 个无效翻译键；桥接超时预算常量化；阅读面板渲染 memo 化；列表分组与切片 memo 化；设置页 Codex 命令路径与扩展目录展示风格统一。
- 主进程错误信息双语化；语言切换后自动更新提示即时刷新。
- ESLint + CI 门禁接入（0 错误 0 漏报）。

## 升级说明

- 请在 `chrome://extensions` 中重新加载 Conversation Manager Bridge（这是最后一次需要手动加载扩展；本次加载的版本已包含自动升级能力，之后的扩展更新将随桌面端自动完成）。
- macOS 用户从 v0.6.x 手动安装本版本后，之后的版本即可通过应用内自动更新完成升级。

## 接口边界

ChatGPT 的项目移动复用网页端同一未公开接口（`PATCH /backend-api/conversation/{id}` 的 `project_id` 字段），随 OpenAI 调整可能失效，失败会以错误提示呈现；Codex 项目接口为 App Server 实验性能力，需要较新版本的 ChatGPT/Codex 桌面客户端。两者均不影响其余功能。
