# Conversation Manager v0.7.8

本版本为统计页新增**成就徽章系统**：8 枚纯本地判定的徽章，记录你与 AI 协作的里程碑——不需要任何服务端，所有判定与记录都留在你的电脑上。

## 成就徽章（新增）

统计页热力图下方新增「成就徽章」卡片，已获得的徽章以品牌底色高亮并标注获得日期，未获得的灰阶显示当前进度（如 `37/100`），头部汇总「已解锁 n/8」：

| 徽章 | 达成条件 |
|---|---|
| 🌱 初来乍到 | 完成第一次同步 |
| 💯 百条俱乐部 | 累计 100 条对话 |
| 🏆 五百俱乐部 | 累计 500 条对话 |
| 🔥 七日不间断 | 连续 7 天都有新会话 |
| 🚀 三十日长跑 | 连续 30 天都有新会话 |
| 🧹 清理大师 | 累计归档 100 条会话 |
| 🌙 深夜攻坚 | 在凌晨 0-5 点活跃过 3 次 |
| ⚔️ 双栖玩家 | ChatGPT 与 Codex 各有 10 条以上 |

### 设计细节

- **一次获得，永久保留**：获得记录持久化在 `stats-daily.json`（徽章 id → 最早获得时间），清空会话缓存或删除会话导致指标回落时，已解锁的徽章不会被收回；重复上报时合并逻辑保留最早时间。
- **全历史 streak 口径**：连续天数徽章按"回算 ∪ 日志"的全历史合并数据判定，不受热力图窗口选择限制；跨月连续与夏令时日长（23/25 小时）均正确处理。
- **零服务端、零内容读取**：判定全部来自本地缓存索引与每日计数日志，不读取会话正文，不发起任何网络请求。
- 深浅色主题适配，中英双语。

## 其他修复

- 修复桌面端本地 `npm run build` 之后再跑测试会误扫 `dist/` 编译产物的问题（vitest 排除通配符由 `dist/**` 改为 `**/dist/**`）。

## 稳健性

- 新增 9 项单元测试（徽章阈值与进度封顶、全历史 streak 的跨月/断档/夏令时、深夜计数、徽章合并的"保留最早"与日志字段保留），桌面端测试总数达 76 项，全部通过；typecheck、ESLint 与中英文案审计通过。

## 升级说明

- 从 v0.7.5 及以上版本正常升级即可，无需任何人工操作；成就判定基于已有的本地数据，升级后首次打开统计页即可看到历史应得的徽章。
- `stats-daily.json` 新增 `badges` 字段为向后兼容的可选字段，旧版本应用读取时自动忽略。
