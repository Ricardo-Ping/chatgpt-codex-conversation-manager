# Conversation Manager v0.2.5

本版本修正浏览器扩展版本号漂移问题，新增外观主题切换，并改进列表与设置的交互。

## 更新内容

- 修正扩展 manifest 版本号从未随发版更新的问题：打包时自动把主程序版本写入扩展 manifest；扩展轮询时上报自身版本，桥接服务记录后由界面展示，版本不一致时侧边栏出现“需重载”黄色提示。
- 单击列表行任意位置即可选中/取消会话，双击打开会话；键盘空格选中、Enter 打开保持不变，行显示手型光标。
- 设置按钮改为切换开关：再次点击返回进入设置前的工作区（ChatGPT 或 Codex），按钮文案随状态变为“返回”。
- 设置页新增“外观”卡片：跟随系统、浅色、深色三种主题可选，选择被持久化，跟随系统时随 Windows 深色模式自动切换。
- 分段切换控件（时间范围、归档状态）增加滑动指示动画，并尊重系统“减少动态效果”设置。

## 接口边界

统一 ChatGPT/Codex 桌面客户端公开的 `codex app-server` 目前只提供 Codex 任务接口，不提供 ChatGPT 云端聊天管理接口。ChatGPT 会话继续通过配套 Chrome/Edge 扩展复用浏览器登录状态；应用不读取桌面客户端私有 Cookie、数据库或凭据文件。

## 文件

- `Conversation-Manager-0.2.5-setup-x64.exe`：Windows x64 安装版，包含卸载程序。
- `Conversation-Manager-0.2.5-portable-x64.exe`：Windows x64 便携版。
- `Conversation-Manager-Bridge-0.2.5.zip`：Chrome/Edge 浏览器桥接扩展。
