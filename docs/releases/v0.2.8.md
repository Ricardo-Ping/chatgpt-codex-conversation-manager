# Conversation Manager v0.2.8

本版本修复单条异常会话记录导致 ChatGPT 同步整体失败的问题。

## 更新内容

- ChatGPT 接口返回的会话列表中若混有 ID 格式异常的条目（如新增的工作类记录），旧版会让整次同步以“Invalid conversation ID”失败并显示 0 条结果。现在改为跳过无法识别的条目、正常入库其余会话；若返回的全部记录都无法识别，则保留本地缓存并给出明确提示，不再清空已有数据。
- 同步期间跳过的异常条目数量与样本会记录在应用日志中，便于后续适配接口变化。

## 接口边界

统一 ChatGPT/Codex 桌面客户端公开的 `codex app-server` 目前只提供 Codex 任务接口，不提供 ChatGPT 云端聊天管理接口。ChatGPT 会话继续通过配套 Chrome/Edge 扩展复用浏览器登录状态；应用不读取桌面客户端私有 Cookie、数据库或凭据文件。

## 文件

- `Conversation-Manager-0.2.8-setup-x64.exe`：Windows x64 安装版，包含卸载程序。
- `Conversation-Manager-0.2.8-portable-x64.exe`：Windows x64 便携版。
- `Conversation-Manager-Bridge-0.2.8.zip`：Chrome/Edge 浏览器桥接扩展。
