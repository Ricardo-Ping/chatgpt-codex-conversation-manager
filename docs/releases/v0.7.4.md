# Conversation Manager v0.7.4

本版本根治扩展自动更新的断链问题（升级后不再需要任何人工重载），修复导出 Codex 会话导致应用冻结的问题，并让阅读面板的本地图片真正渲染出来。

## 扩展自动更新闭环（根治）

- 修复自动重载断链的根因：扩展的 Service Worker 靠高频轮询长期存活，桌面端更新磁盘上的扩展文件后，运行中的 SW 仍在执行内存里的旧代码——这就是「扩展 v0.7.x · 需重载」提示反复出现、需要人工去 chrome://extensions 重载的原因。
- 三层修复：① 桌面端启动时把最新扩展同步到固定稳定目录；② 检测到 Chrome/Edge 实际加载的扩展目录落后时，自动把新文件写入该目录（自愈）；③ 桥接响应携带硬重载提示头，扩展轮询到后立即重启加载新代码（带防风暴守卫）。
- 升级到本版本并按引导切换一次目录后，扩展将永久随桌面端自动更新，全程零人工操作。

## 导出 Codex 会话不再冻结

- 修复点击「导出 Codex 会话」后应用假死的问题：数百 MB 会话数据的压缩此前运行在主进程事件循环上，导致整个应用"未响应"。
- 现在打包与导入都在独立 worker 线程执行（自包含打包为 29KB 的 worker 文件随安装包分发），主界面全程可正常操作。
- 新增实时进度提示：「正在收集 Codex 会话…」→「正在压缩 N 个会话…」。

## ChatGPT 读取与图片显示修复

- 修复本地路径图片在阅读面板中永远无法显示的问题：DOMPurify 默认 URI 白名单会剥掉本地路径的图片地址，导致转换功能从未生效。现在本地图片按 `~/.codex` 白名单正常渲染。
- 扩展消息转发增加 60 秒响应限时与多标签容错（优先最近使用的标签页），标签页冻结/无响应时快速返回明确错误，不再无限挂起。

## 统计洞察面板（抛光）

- 项目 Top 8 自动解析 ChatGPT/Codex 项目名称（此前显示内部 ID）；缺失时回退为「未命名项目 + 短 ID」。
- 平台占比环形图改为环心显示总会话总数，移除悬空标签；趋势图与 tooltip 统一为主题化样式。
- 修复统计页边界与滚动：与工作区/设置页相同的容器约束，可顺畅下滑至页面底部。

## 会话列表（抛光）

- 虚拟滚动下分组头保持单行：超长文件夹名省略号截断，不再与计数/路径及下方会话行挤压换行。

## 工程化

- 主进程拆分出 updater / preferences / ipc-sanitize / extension-sync / extension-heal / archive-worker 模块；共享纯函数收拢到共享包并补齐单元测试（总计 65 个）。
- 构建流程新增 esbuild 步骤打包 worker 文件；`pnpm bump` 版本同步覆盖 Codex 适配器版本常量；硬重载提示头与本地 API 均有桥接服务测试覆盖。

## 升级说明

- **从 v0.7.2 / v0.7.3 升级**：安装或自动更新完成后，请按设置 → 浏览器桥接页内的指引，把 Chrome/Edge 的扩展目录切换为「打开扩展目录」指向的稳定目录——这是最后一次人工操作，此后扩展永久自动更新。
- 升级后 ChatGPT 读取若仍超时，新版会在约 1 分钟内给出明确的错误原因（刷新标签页 / 检查网络代理），不再无限挂起。

## 接口边界

`codex://` 深链依赖 ChatGPT 桌面客户端的协议注册，未安装客户端时自动回退终端方案；会话迁移与统计基于本地 `~/.codex` 存档与缓存索引。
