# Conversation Manager v0.2.3

本版本重构界面为侧边栏布局，补全键盘操作，并让自动更新全程无人工参与。

## 更新内容

- 界面改为左侧边栏布局：平台切换、桥接与 App Server 连接状态指示灯移至侧边栏，列表利用全部宽度；未归档/已归档/已安排变为带数量徽标的侧边状态栏。
- 列表行改为两行结构：标题加正文预览（Codex），时间显示为相对时间，完整时间悬停可见；运行中的 Codex 任务以呼吸状态圆点标识。
- 新增键盘操作：上下方向键移动行焦点，空格选中，Enter 打开，`/` 聚焦搜索，`Ctrl/Cmd+A` 全选当前结果，Delete 快捷归档，Esc 清空选择。
- 删除确认改为应用内对话框，列出将被删除的标题；超过 20 条仍需输入数量确认，永久删除按钮与归档/恢复按钮分区摆放。
- 安装版检测到更新下载完成后 5 秒自动静默安装并重启，全程无需点击；关闭自动检查后仍可手动检查与安装。
- 修复 Codex 分组：桌面端为未挂项目会话自动创建的临时目录不再被误标为独立项目，优先按项目 ID 分组。

## 接口边界

统一 ChatGPT/Codex 桌面客户端公开的 `codex app-server` 目前只提供 Codex 任务接口，不提供 ChatGPT 云端聊天管理接口。ChatGPT 会话继续通过配套 Chrome/Edge 扩展复用浏览器登录状态；应用不读取桌面客户端私有 Cookie、数据库或凭据文件。

## 文件

- `Conversation-Manager-0.2.3-setup-x64.exe`：Windows x64 安装版，包含卸载程序。
- `Conversation-Manager-0.2.3-portable-x64.exe`：Windows x64 便携版。
- `Conversation-Manager-Bridge-0.2.3.zip`：Chrome/Edge 浏览器桥接扩展。
