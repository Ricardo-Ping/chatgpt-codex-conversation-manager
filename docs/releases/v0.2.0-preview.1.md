# Conversation Manager v0.2.0-preview.1

这是桌面端架构预览版本，产品已从长对话导航器重构为专注于 ChatGPT 与 Codex 历史记录整理的 Conversation Manager。

## 主要变化

- 全新无侧栏桌面界面，集中提供搜索、时间筛选、排序、多选、归档、恢复和永久删除。
- ChatGPT 改用 Chrome/Edge 配套扩展复用浏览器登录，管理器不再要求重复登录。
- Codex 直接连接本机 `codex app-server`，支持未归档和已归档任务管理。
- 新增最小本地会话索引，启动先显示缓存，再执行后台同步；完整刷新用于权威校准。
- “已安排”只读取真实活动安排，不再混入普通聊天。
- 批量删除仅在服务端明确确认后更新缓存，并防止旧分页结果让已删除记录重新出现。
- 安装版默认自动检查、下载并在退出时安装 GitHub Release 更新；便携版提示手动下载。

## 下载说明

- `Conversation-Manager-0.2.0-preview.1-setup-x64.exe`：Windows x64 安装版。
- `Conversation-Manager-0.2.0-preview.1-portable-x64.exe`：Windows x64 便携版。
- `Conversation-Manager-Bridge-0.2.0-preview.1.zip`：Chrome/Edge 浏览器桥接扩展。
- `SHA256SUMS.txt`：发布文件校验值。

首次使用 ChatGPT 管理功能时，请解压桥接扩展 ZIP，在 Chrome/Edge 扩展管理页开启开发者模式并加载该目录，然后按应用内提示完成一次配对。

## 预览版限制

- 当前仅发布 Windows x64；macOS 尚未提供安装包。
- 浏览器桥接扩展尚未上架扩展商店。
- ChatGPT 管理依赖网页内部接口；检测到接口不兼容时会自动切换为只读缓存。
- 本次自动化验证未对真实账号执行归档、恢复或删除。
