# Conversation Manager v0.2.2

本版本修复浏览器桥接已配对但无法读取会话的问题，并改善 Codex 任务的项目组织方式。

## 更新内容

- ChatGPT 标签页缺少桥接脚本时自动补注入并重试，不再要求手动刷新网页。
- 错误提示不再显示 Electron IPC 内部前缀。
- Codex 任务按工作目录显示为可折叠项目文件夹，没有工作目录的任务归入“非项目任务”。
- 安装版下载更新后静默安装，避免重复显示安装向导。

## 接口边界

统一 ChatGPT/Codex 桌面客户端公开的 `codex app-server` 目前只提供 Codex 任务接口，不提供 ChatGPT 云端聊天管理接口。ChatGPT 会话继续通过配套 Chrome/Edge 扩展复用浏览器登录状态；应用不读取桌面客户端私有 Cookie、数据库或凭据文件。

## 文件

- `Conversation-Manager-0.2.2-setup-x64.exe`：Windows x64 安装版，包含卸载程序。
- `Conversation-Manager-0.2.2-portable-x64.exe`：Windows x64 便携版。
- `Conversation-Manager-Bridge-0.2.2.zip`：Chrome/Edge 浏览器桥接扩展。
