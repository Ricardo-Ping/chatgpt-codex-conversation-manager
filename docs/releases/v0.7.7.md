# Conversation Manager v0.7.7

本版本包含两部分：**同步命令生命周期的结构性重构**（彻底告别「固定预算猜数字」的超时模型）与**全新的统计洞察面板**（会话热力图 + 趋势/占比）。

## 同步：从「固定预算」重构为「活性窗口」

上一版（v0.7.6）修复了队列堆积与命令过期，但慢网络/项目多时，`list` 命令总耗时仍可能超过桌面端预算而误报「同步或操作超时」。根因是**命令生命周期管理模型**：创建命令时定死超时时间，扩展慢就被误杀；调大预算又牺牲失败响应速度——无论设多少秒都是猜。

本版改变模型本身：

- **命令活性心跳**：扩展在命令执行期间每 15 秒上报一次心跳（`POST /v1/progress`），桌面端收到心跳就把该命令的超时窗口**重置为完整预算**——只要命令在推进就继续等，完整校准跑几分钟也不会被误杀。
- **真卡死才会超时**：扩展停止心跳（命令结束/失败、扩展 Service Worker 异常）后，窗口到期才超时；超时必有日志（此前「扩展在线但命令真超时」路径完全无痕，无法诊断）。
- **完全向后兼容**：旧扩展不发心跳，行为退化为固定预算超时；命令协议与配对方式不变，`protocolVersion` 仍为 1。
- 配套加固：单请求限时 45s → 20s（正常分页接口 <2 秒，慢请求快速失败不再拖死转发队列）；429 限流退避 250ms → 500ms 倍增；`chatgpt:list` 独立预算 600s（批量/读取仍 300s）；完整刷新时界面提示「可能需要几分钟」。

## 统计洞察面板（新增）

应用内新增「统计」页（设置/导航入口进入），基于本地缓存索引做只读洞察，不额外读取任何会话正文：

- **会话热力图**：GitHub 风格日历热力图，支持近 12 个月 / 今年 / 去年，4 档色阶；头部显示总量、最长连续天数、最活跃的一天、日均。
- **新增趋势**：近 7 / 30 / 90 天可切换，按平台（ChatGPT / Codex）堆叠展示每日新增。
- **平台占比** 与 **项目 Top 8**：原有图表保留并优化（饼图标签、配色语义化）。
- **双层数据保证不缩水**：热力图数据 = 缓存索引实时回算 ∪ 本地每日日志（`stats-daily.json`，仅存计数不存内容）逐日取最大值——清空缓存或删除会话后，历史活动峰值仍保留；主进程对 IPC 入参做格式/数量/数值三重校验，写盘采用原子替换。
- 空数据引导、深浅色主题适配、中英双语。

## 稳健性

- 全量回归：扩展 20 项、桥接服务 17 项（新增「心跳刷新超时窗口」测试）、桌面 67 项（含统计 13 项新增）、adapter 4 项、domain 7 项、MCP 1 项测试全部通过；`tsc` 与 ESLint 通过。
- 同步修复分布在桥接服务（心跳端点）与扩展（执行心跳）两侧；统计面板全部位于桌面端 renderer/main，不影响扩展与桥接协议。

## 升级说明

- 从 v0.7.6 正常升级的用户：无需任何操作。桌面端会自动更新扩展文件并触发扩展自我重载，新同步逻辑立即生效。
- 仍偶发同步超时的用户：安装本版本后如果再次遇到超时，请把运行日志中 `bridge … timed out while connected; extension staleness=…, hash=…` 一行发给我们——本版起该路径必有日志，可直接定位。
