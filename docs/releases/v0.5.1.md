# Conversation Manager v0.5.1

本版本提供 macOS（Apple Silicon）预览版，并包含双语导出与若干修复。

## 更新内容

- 新增 macOS（Apple Silicon）预览版：基于 Electron.app 骨架打包的未签名 zip。由于未经 Developer ID 签名，首次运行需要执行一次修复脚本（解压后运行 zip 内的 `mac-fix.sh`，会补全应用名、临时签名并移除隔离标记），之后即可正常打开。macOS 版暂不支持自动更新，新版本请从 Releases 页面手动下载。
- 修复导出会话时的账号解析错误：此前读取会话正文使用了错误的账号标识，导致 ChatGPT 端导出必然鉴权失败；已改为与其他命令一致的账号解析方式，并补充单元测试。
- 导出的 Markdown 文件跟随界面语言：英文界面导出英文结构的文档，中文界面保持中文结构。
- “保存会话”会记住上次使用的导出目录，下次保存自动定位。
- 扩展弹窗与配对错误提示跟随浏览器语言双语显示。
- macOS 版包含应用菜单（Cmd+C/V/Q 可用）与深色模式支持。

## macOS 预览版使用说明

1. 解压 `Conversation-Manager-0.5.1-mac-arm64.zip`。
2. 打开终端，进入解压目录，运行 `sh mac-fix.sh`（需要一次，用于补全应用名与本地签名）。
3. 双击 “Conversation Manager.app” 打开；浏览器扩展按提示配对后即可使用。
4. 同步与保存功能需要 Chrome/Edge 安装配套扩展并保持 chatgpt.com 页面打开。

## 接口边界

统一 ChatGPT/Codex 桌面客户端公开的 `codex app-server` 目前只提供 Codex 任务接口，不提供 ChatGPT 云端聊天管理接口。ChatGPT 会话继续通过配套 Chrome/Edge 扩展复用浏览器登录状态；应用不读取桌面客户端私有 Cookie、数据库或凭据文件。

## 文件

- `Conversation-Manager-0.5.1-setup-x64.exe`：Windows x64 安装版，包含卸载程序。
- `Conversation-Manager-0.5.1-portable-x64.exe`：Windows x64 便携版。
- `Conversation-Manager-0.5.1-mac-arm64.zip`：macOS（Apple Silicon）预览版，未签名。
- `Conversation-Manager-Bridge-0.5.1.zip`：Chrome/Edge 浏览器桥接扩展。
