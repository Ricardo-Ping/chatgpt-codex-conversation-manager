# Conversation Manager v0.7.1

本版本带来 Codex 会话一键迁移、修复「在终端打开」无法唤起终端的问题，并补全英文界面翻译；同时为阅读面板图片与文件引用显示、CI 门禁等做了多项打磨。

## Codex 会话迁移（新）

- 设置页新增「Codex 会话迁移」：一键把本机全部 Codex 会话（含归档会话，即 `~/.codex/sessions` 与 `archived_sessions` 下的全部 rollout 存档）打包为单个 zip 文件。
- 在其他电脑上选择该 zip 一键导入，会话按原路径合并回本地存档；同名会话自动跳过，重复导入幂等。
- 导入对 zip 条目做路径白名单校验，拒绝目录穿越等非法路径。
- 刻意不包含 `auth.json` 与 `config.toml`：新电脑使用自己登录的 Codex 账号即可继承会话记录，凭据永不出机器。
- 实测参考：91 个会话（约 936 MB）压缩为约 488 MB 的 zip，耗时约 17 秒。

## 修复「在终端打开」Codex 会话

- 修复点击阅读面板「在终端打开」后毫无反应的问题：原先以 detached 方式启动的 PowerShell 在 Windows 上会静默退出、命令根本不执行。
- 现改为隐藏启动器 + `Start-Process`，为 codex 创建真正可见的控制台窗口；macOS 同步修复为通过 AppleScript 在 Terminal.app 中打开（原先同样无法唤起终端）。
- Codex 命令路径失效（客户端升级导致版本目录变化）或启动失败时，自动回退为复制恢复命令到剪贴板并明确提示，不再假装成功。

## Codex 阅读面板显示修复

- 修复 Codex 消息中的文件引用标记（file-citation）以原始标记形式显示的问题，现转换为可读的文件引用。
- 修复阅读面板中本地文件路径图片无法显示的问题，现转换为 `file:///` URL 后正常内联展示。
- 清理 Codex 消息正文中的关联会话 JSON 杂块，阅读更干净。

## 界面与翻译

- 补全「数据备份」「跳转顶部」「移动到项目」等十余个英文界面缺失翻译键。
- 新增翻译键审计脚本并接入 CI：任何 `t()` 键缺失英文翻译都会在合并前拦截。
- 设置页移除已废弃的 Codex 项目管理入口，界面更聚焦。

## 其他

- 修复项目管理中 Electron 不兼容的 `prompt()` 调用。
- ChatGPT 导出 Markdown 时内联嵌入图片。
- 新增 push/PR 触发的 CI 门禁（i18n 审计 + typecheck + test + lint）；修复 vitest 排除参数在 Linux 下因 bash 通配符展开导致的 CI 失败。

## 升级说明

- 扩展随桌面端自动升级，无需手动操作；从旧版本升级后如扩展未自动重载，在 `chrome://extensions` 中刷新一次即可。
- macOS 用户安装本版本后，后续版本可继续通过应用内自动更新升级。

## 接口边界

Codex 会话迁移依赖 `~/.codex` 下的 rollout 存档格式，随 OpenAI 客户端大版本调整可能变化；导入时以文件名为会话唯一标识。其余功能不受影响。
