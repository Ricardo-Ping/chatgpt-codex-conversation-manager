# Conversation Manager v0.2.1

本补丁版本修复正式版首次真实安装验证中发现的连接问题。

## 修复与改进

- 浏览器扩展改为点击一次即可完成本机配对，不再手工生成和输入六位配对码。
- 修正 ChatGPT 项目会话接口的分页参数，解决同步结束时报 `422`、无法显示会话的问题。
- 422 等接口错误会显示经过过滤的服务端说明，便于诊断且不暴露账号数据。
- 自动发现统一 ChatGPT/Codex Windows 桌面客户端附带的 `codex.exe`，并连接其 `app-server`。
- 自动检测成功时不再要求手动选择 Codex 可执行文件；手动选择仅作为兜底。

## 安装

- `Conversation-Manager-0.2.1-setup-x64.exe`：Windows x64 安装版，可从 Windows“已安装的应用”卸载。
- `Conversation-Manager-0.2.1-portable-x64.exe`：Windows x64 便携版。
- `Conversation-Manager-Bridge-0.2.1.zip`：Chrome/Edge 浏览器桥接扩展。

升级桌面应用后，请在浏览器扩展管理页重新加载 `v0.2.1` 扩展，再点击扩展中的“一键连接桌面管理器”。
