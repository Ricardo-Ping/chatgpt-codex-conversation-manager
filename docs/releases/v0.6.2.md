# Conversation Manager v0.6.2

本版本让 ChatGPT 与 Codex 的项目管理能力对齐：两个工作区都支持按项目分组展示，并可在会话上右键直接加入或移出项目，操作实时同步回 OpenAI。macOS 转正：内置自研自动更新，不再是从 Releases 页面手动下载的预览版。

## 更新内容

### 项目管理（ChatGPT + Codex）

- ChatGPT「项目工作」视图与 Codex 任务列表一致，按项目分组折叠展示，分组标题为项目名称。
- 会话列表支持右键菜单：「添加到项目」（悬停展开项目子菜单）、「移出项目」、「打开」。
- ChatGPT 的项目移动通过浏览器桥接调用官方网页同款接口完成；Codex 通过 App Server 的 `thread/metadata/update` 完成，项目列表来自 `project/list`。
- 操作完成后本地缓存、侧边栏计数与列表即时更新；在 ChatGPT「聊天」视图把会话加入项目后，会话自动归入「工作」视图。

### macOS 自动更新（正式版）

- 未签名应用无法使用 Squirrel.Mac，现改为自研替换式更新器：检查 GitHub Releases → 下载 zip（带进度与 SHA256 校验）→ 原地原子换包 → 自动重启。
- 自动更新开启时全程无感；应用目录不可写时明确提示，并保留「打开下载页」手动兜底。
- 设置页新增「下载更新」按钮，与 Windows 一致展示更新进度。

### 浏览器桥接

- 移除配对码：扩展与桌面端全面自动配对，无需任何手动配对流程；设置页保留「清除配对」用于重置。
- 首次使用的连接引导卡片与设置页新增「扩展目录」展示与「复制路径」按钮，并附 chrome://extensions 加载步骤说明。

### 体验修复

- 修复 Codex 侧边栏有时只显示「未归档」或只显示「已归档」一个计数的问题：启动即同时拉取两个状态，批量操作后计数合并而非整体替换。
- 修复切换语言后自动更新提示仍是旧语言的问题。
- 补全英文界面缺失的翻译（缓存统计、Codex 状态、同步提示、右键菜单等），主进程错误信息接入双语字符串表。

## 升级说明

- 更新后请在 `chrome://extensions` 中重新加载 Conversation Manager Bridge：项目管理功能依赖扩展新版本。
- Codex 项目管理需要较新版本的 ChatGPT/Codex 桌面客户端（App Server 需支持实验性项目接口）；不支持时项目列表显示为空，其余功能不受影响。
- macOS 用户首次仍需手动安装本版本，之后的更新可在应用内直接完成。

## 接口边界

ChatGPT 项目操作复用网页端同一未公开接口（`PATCH /backend-api/conversation/{id}` 的 `project_id` 字段），随 OpenAI 调整可能失效，失败会以错误提示呈现；Codex 项目接口为 App Server 实验性能力。应用不读取桌面客户端私有 Cookie、数据库或凭据文件，浏览器令牌始终留在浏览器内。
