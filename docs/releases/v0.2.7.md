# Conversation Manager v0.2.7

本版本区分 ChatGPT 的聊天与项目工作会话，把状态切换收拢进侧边栏，并修正同步通知的显示。

## 更新内容

- ChatGPT 页新增“聊天 / 工作”切换：项目相关会话默认从聊天列表隐藏、只在 Codex 页管理，需要时切换“工作”视图即可查看和操作，标题随之显示为“ChatGPT 项目工作”。
- 未归档/已归档/已安排状态切换从工作区移入侧边栏，与平台导航、连接状态集中一处；ChatGPT 的三档状态保留数量徽标，两个平台各自记住自己的状态，切换平台后互不干扰；工作区改为单列布局，列表更宽。
- 修复点击“完整刷新”后仍显示上一次批量操作结果的问题：刷新会清除旧的操作通知，同步完成的提示改为显示当前状态的会话数量（如“完整校准完成：共 38 条任务”）。
- 重写中英文 README：补充侧边栏导航、键盘操作、聊天/工作区分、深色模式、扩展自动配对与静默安装更新的说明。

## 升级说明

更新后请在 `chrome://extensions` 中重新加载 Conversation Manager Bridge，使浏览器内扩展同步到新版本；版本不一致时侧边栏会出现黄色“需重载”提示。

## 接口边界

统一 ChatGPT/Codex 桌面客户端公开的 `codex app-server` 目前只提供 Codex 任务接口，不提供 ChatGPT 云端聊天管理接口。ChatGPT 会话继续通过配套 Chrome/Edge 扩展复用浏览器登录状态；应用不读取桌面客户端私有 Cookie、数据库或凭据文件。

## 文件

- `Conversation-Manager-0.2.7-setup-x64.exe`：Windows x64 安装版，包含卸载程序。
- `Conversation-Manager-0.2.7-portable-x64.exe`：Windows x64 便携版。
- `Conversation-Manager-Bridge-0.2.7.zip`：Chrome/Edge 浏览器桥接扩展。
