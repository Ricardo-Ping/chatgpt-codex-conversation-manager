# Conversation Manager v0.7.9

维护版本：成就徽章的体验细节打磨，以及桥接服务与测试基础设施的稳定性加固。无功能变更、无数据迁移。

## 成就徽章（细节打磨）

- **获得日期按本地时区显示**：此前使用 UTC 日期切片，凌晨 0-8 点解锁的徽章会显示成"昨天"；现在按本地日历日期展示。
- **上报防御**：徽章获得记录的上报增加旧 preload 防御，开发/热更新场景下不再可能出现未处理异常。

## 桥接服务与测试稳定性

- `ChatGptBridgeServer.close()` 现在会复位绑定的端口号：关闭后调用 `port()` 不再返回陈旧值。
- 全部桥接测试改用**操作系统分配的临时端口**（port 0 + 回读实际端口），彻底消除测试随机端口段与并发进程（正在运行的应用、其他测试进程）碰撞导致的偶发 `ECONNREFUSED`。
- 「进度心跳保活」测试重写为确定性时序（200ms 预算 / 25ms 心跳 / 400ms 执行窗口），彻底移除贴边余量；心跳 fetch 自带 catch、settled 处理器创建时同步挂载，不再可能以 unhandled rejection 击穿测试进程。连续 6 轮运行稳定通过。

## 工程化

- 新增 `npm run verify`：**不依赖 pnpm** 的一键全量校验——按 workspace 拓扑序对 6 个包依次执行 build → typecheck → test，最后跑根级 lint；任一步失败立即终止并打印失败包的输出末尾。任何环境一条命令即可获得与 CI 等价的验证结果。
- 新增 pre-push 钩子（`npm run setup:hooks` 一次性启用）：每次推送前自动执行全量校验，把「本地没验证、CI 反复挂」的问题挡在本地。
- 修复 vitest 排除通配符（`dist/**` → `**/dist/**`）：本地 build 之后再跑测试，不再误扫 `dist/` 里的编译产物测试文件。

## 稳健性

- 桌面端 76 项、桥接服务 17 项、扩展 20 项等全部单元测试通过；typecheck、ESLint、中英文案审计通过；全部改动经 `verify-all` 全量门禁验证后推送。

## 升级说明

- 从 v0.7.8 正常升级即可，无需任何人工操作。
