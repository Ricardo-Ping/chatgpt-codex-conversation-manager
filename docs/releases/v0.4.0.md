# Conversation Manager v0.4.0

本版本新增中英双语界面，并优化同步速度与运行韧性。

## 更新内容

- 新增界面语言切换：设置 → 外观中可在中文与 English 之间切换，选择持久化保存，即时生效；默认简体中文。
- 主进程与渲染层的全部界面文案已接入双语词典，更新提示、对话框与错误信息随语言切换。
- 同步提速：
  - 项目会话改为 3 路并行拉取，完整校准时间明显缩短。
  - 命令下发改为长轮询：扩展取命令的等待时间从最长 30 秒降低到接近零。
  - 读取接口遇到 429/5xx 时自动退避重试，减少同步失败。
- 保存会话的导出改为 3 路并行读取正文，多选保存更快。
- 桥接端口被占用时应用降级继续运行（桥接显示未连接），不再导致启动失败。
- 日志优化：同一条坏数据样本只告警一次，不再重复刷屏。
- 开发/测试场景支持通过 `CM_USER_DATA_DIR` 环境变量隔离数据目录。

## 升级说明

更新后请在 `chrome://extensions` 中重新加载 Conversation Manager Bridge，使浏览器内扩展同步到新版本；版本不一致时侧边栏会出现黄色“需重载”提示。

## 接口边界

统一 ChatGPT/Codex 桌面客户端公开的 `codex app-server` 目前只提供 Codex 任务接口，不提供 ChatGPT 云端聊天管理接口。ChatGPT 会话继续通过配套 Chrome/Edge 扩展复用浏览器登录状态；应用不读取桌面客户端私有 Cookie、数据库或凭据文件。

## 文件

- `Conversation-Manager-0.4.0-setup-x64.exe`：Windows x64 安装版，包含卸载程序。
- `Conversation-Manager-0.4.0-portable-x64.exe`：Windows x64 便携版。
- `Conversation-Manager-Bridge-0.4.0.zip`：Chrome/Edge 浏览器桥接扩展。
