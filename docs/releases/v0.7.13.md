# Conversation Manager v0.7.13

小版本：**ChatGPT 会话行补齐会话 ID 展示与复制**，与 Codex 任务行的体验完全统一。纯界面增强，无行为变更、无数据迁移。

## ChatGPT 会话行：会话 ID 与复制

- 会话标题下方新增小字元信息行，显示中段省略的会话 ID（如 `01a0d480…90d09e`），悬停可看完整 ID——与 Codex 任务行同款样式。
- 行右侧新增**复制会话 ID** 按钮，一键复制完整 ID，成功后图标变为 ✓ 反馈。
- 按平台合理裁剪：打开文件夹 / 打开会话文件按钮与 Token 用量徽标仍为 Codex 专属——ChatGPT 会话保存在云端，没有本地日志文件，官方接口也不提供 Token 计量，硬做只能是误差很大的估算（详见 v0.7.12 说明中的数据来源差异）。

## 稳健性

- 桌面 96 项单元测试、typecheck、ESLint、中英文案审计全部通过；`verify-all` 全量门禁与 pre-push 钩子验证；布局经浏览器实测（宽 / 窄两种列表宽度，含虚拟滚动行高与窄列表自适应隐藏）。

## 升级说明

- 从 v0.7.x 正常升级即可，无需任何人工操作。扩展随桌面端自动更新；已有缓存与账号数据不受影响。
