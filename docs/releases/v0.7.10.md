# Conversation Manager v0.7.10

本版本聚焦两件事：**扩展重载后的自我修复**（同步不再需要人工刷新标签页）与**统计页的交互升级**（趋势图按平台切换、热力图对齐 GitHub 风格）。

## 扩展自愈：彻底告别「请刷新 ChatGPT 标签页」

扩展自更新会把已打开的 ChatGPT 标签页"孤儿化"（页面里的旧内容脚本与扩展断开），此前用户需要手动刷新每个标签页才能恢复同步，且扩展错误页会不断累积 `onMessage of undefined` 报错。本版本实现全自动恢复：

- **死世界守卫**：内容脚本启动时检测扩展上下文是否已失效，孤儿化后静默退出——错误页不再累积噪音。
- **存活探测 + 自动 reload**：后台转发命令前先探测每个候选标签页（1.5 秒超时），无应答（孤儿化/被浏览器内存节省程序丢弃/被冻结）即自动 reload 并等待加载完成，ChatGPT 页面刷新即恢复、会话与草稿原样保留。夜间或久置后的首次自动同步直接自愈，**全程零人工操作**。
- **明确的最终指引**：极端情况下标签页确实无法自愈时，同步错误会明确提示「扩展更新后此标签页尚未刷新，请刷新该标签页以恢复同步」，而不是缺失字段的空结果。
- 修复一个存量缺陷：所有标签页都无应答时，转发结果缺少 `ok` 字段即上报（`result` 未初始化绕过了指引判定）。

## 启动自动同步：温和重试代替误报

- 打开应用时的自动同步若撞上休眠/丢弃的标签页或扩展重载竞态，不再立即显示「同步或操作超时」的终态横幅，而是**自动重试最多 2 次（15s / 30s 退避）**并显示「自动同步暂时失败，N 秒后自动重试…」；重试成功即无缝恢复。手动点击「完整刷新」仍立即失败、立即反馈，行为不变。

## 统计页升级

- **趋势图按平台切换**：卡片头新增 `全部 / ChatGPT / Codex` 分段切换器，与时间范围切换器并排。切换只对已加载的快照数据重新渲染——零延迟、零重新统计。单平台视图展示该平台的独立柱状分布，标题随之变化。
- **热力图对齐 GitHub 风格**：格子改为 13×13 正方形并整体居中（此前宽度拉伸成横长条）；移除 ECharts 默认的月份阶梯分隔线，月份只靠顶部标签区分——更干净、更接近 GitHub Contribution Graph 的呈现。
- 成就徽章的获得日期改为**本地时区**显示（此前 UTC 切片会让凌晨解锁的徽章显示成"昨天"）。

## 工程化

- 桥接服务测试全面改用**操作系统分配的临时端口**（port 0 + 回读），消除随机端口段与并发进程的碰撞；「进度心跳」测试重写为确定性时序（200ms 预算 / 25ms 心跳 / 400ms 窗口），连续多轮运行稳定，不再偶发失败。
- 测试 fetch 增加瞬时网络错误（bad port / ECONNREFUSED 等）单次重试，重负载下不再偶发失败。
- `relayJob` 可测试化：新增 3 项转发自愈测试（孤儿后台标签页自动 reload、存活标签页不误刷、无法自愈时的明确指引）。

## 稳健性

- 扩展 23 项、桥接服务 17 项、桌面 76 项等全部单元测试通过；typecheck、ESLint、中英文案审计通过；所有改动均经 `verify-all` 全量门禁与 pre-push 钩子验证。

## 升级说明

- 从 v0.7.x 正常升级即可，无需任何人工操作。扩展更新后残留的旧标签页错误可点击错误页「全部清除」；今后扩展重载将自动自愈，不再需要手动刷新标签页。
