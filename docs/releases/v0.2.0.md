# Conversation Manager v0.2.0

首个正式版本，专注管理 ChatGPT 会话与本机 Codex 任务，不再包含长对话导航和正文阅读功能。

## 主要功能

- ChatGPT 通过 Chrome/Edge 配套扩展复用浏览器登录，无需在应用内重复登录。
- Codex 通过本机 `codex app-server` 读取和管理任务。
- 支持标题搜索、时间筛选、状态筛选、排序、多选和全选当前结果。
- 支持归档、恢复和带二次确认的永久删除。
- “已安排”仅显示真实活动安排，不混入普通聊天。
- 本地保存最小会话索引，启动优先显示缓存并在后台增量同步。
- 删除结果经服务端确认后立即从缓存和选择中移除，并防止旧分页数据让记录重新出现。
- 安装版默认自动检查并下载 GitHub Release 更新；便携版提供手动下载入口。

## 下载

- `Conversation-Manager-0.2.0-setup-x64.exe`：Windows x64 安装版，安装后可从 Windows“已安装的应用”卸载。
- `Conversation-Manager-0.2.0-portable-x64.exe`：Windows x64 便携版，无需安装。
- `Conversation-Manager-Bridge-0.2.0.zip`：Chrome/Edge 浏览器桥接扩展。
- `SHA256SUMS.txt`：发布文件 SHA-256 校验值。

## 限制

- 当前未发布 macOS 版本。
- 浏览器桥接扩展暂通过 ZIP 分发，尚未上架扩展商店。
- ChatGPT 会话管理依赖网页内部接口；检测到不兼容时会安全切换为只读缓存。
