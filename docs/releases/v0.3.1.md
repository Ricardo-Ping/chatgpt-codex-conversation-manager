# Conversation Manager v0.3.1

本版本改善同步健壮性与操作可见性，并统一应用图标。

## 更新内容

- ChatGPT 工作区“完整刷新”旁新增“打开 ChatGPT”按钮，桥接需要网页端配合时可以一键打开登录页面。
- 浏览器扩展在转发桌面命令期间主动保持 Service Worker 活跃，长事务（如完整校准）不再因后台休眠而中途超时。
- 向 ChatGPT 标签页注入桥接脚本后改为带退避的多次重试，降低首次同步偶发失败的概率。
- 应用事件（启动、更新下载、异常记录跳过等）写入本地日志文件 `logs/main.log`（自动轮转），便于排查问题。
- Codex 页切换未归档/已归档时先用缓存即时渲染，再后台刷新，不再白屏等待。
- 侧边栏计数徽标跟随当前聊天/工作视图分别显示；深色模式下启动不再闪白；Codex 项目文件夹的折叠状态在重启后保留。
- 同步后台轮转扩展到全部三个会话状态：当前视图每 10 分钟增量同步，其余状态每 30 分钟轮转，距上次完整校准满 6 小时自动升级为全量。

## 接口边界

统一 ChatGPT/Codex 桌面客户端公开的 `codex app-server` 目前只提供 Codex 任务接口，不提供 ChatGPT 云端聊天管理接口。ChatGPT 会话继续通过配套 Chrome/Edge 扩展复用浏览器登录状态；应用不读取桌面客户端私有 Cookie、数据库或凭据文件。

## 文件

- `Conversation-Manager-0.3.1-setup-x64.exe`：Windows x64 安装版，包含卸载程序。
- `Conversation-Manager-0.3.1-portable-x64.exe`：Windows x64 便携版。
- `Conversation-Manager-Bridge-0.3.1.zip`：Chrome/Edge 浏览器桥接扩展。
